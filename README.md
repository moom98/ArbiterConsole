# Arbiter Console

## Overview

**Arbiter Console** is a Decision Support application for chess tournament arbiters.

This system assists human arbiters in making informed decisions during chess tournaments. It is **not** an automated ruling system—the final judgment always remains with the human arbiter.

## Project Status

Currently in **requirements and design phase**.

Application implementation has not yet started.

## Purpose

Chess tournaments involve complex rulings that require:
- Knowledge of FIDE Laws of Chess
- Understanding of tournament-specific rules
- Consideration of incident history
- Quick decision-making under pressure

Arbiter Console supports arbiters by:
- Providing quick access to relevant rules
- Suggesting possible ruling options with sources
- Recording incident history
- Ensuring consistency across rulings
