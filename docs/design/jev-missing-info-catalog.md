## A. 不足情報カタログ

### 使い方（設計書 §5.2 の要約）

1. Jev には、匿名化した報告（semantic state）について、各項目を「書かれていないか」の yes/no で尋ねます。
2. 分類されたカテゴリの項目のうち、確率が 0.5 以上のものを確率の高い順に最大5件、「不足している情報」として表示します。
3. 文言は**固定**です。AI が生成した文章は表示しません。裁定はせず、確認を促すだけです。

### 採録の基準

- **入れるもの**：裁定を変える可能性があり（要件 §12）、**報告文に書かれうる**事実。
- **入れないもの**：アプリが既に持っている事実。
  - 対局種別（Standard / Rapid / Blitz）
  - 同じ選手の違反回数（Incident Log から分かる）
  - 監督体制
  - 大会規定の内容
  - 盤上の駒数・局面（決定木で確認する）

### 根拠欄の見方

- `§nn`：`docs/requirements/product-requirements.md` の節
- `DT:xxx`：決定木の質問 ID（`lib/domain/follow-up.ts` の `QUESTIONS`）
- `IC§n`：`docs/design/incident-classification.md` の節（各サブタイプの「Key Questions」）
- **要確認**：要件に直接の記載がない項目です。採用するか、文言をどうするかを判断してください。

### 対象外のカテゴリ

- **fair-play**：一切送信しない（設計書 §4.4）ので、カタログはありません。

## B. 送信禁止語（センシティブ判定。設計書 §4.4 step 1）

### 仕組み

- 次のいずれかに当たる報告は、TypeSafe にもサーバーにも送らず、端末内のキーワード分類だけを使います。
- 判定は、報告の全文に対して切り詰める前に行います。
- 判定の前に、次の正規化を行います。
  - NFKC 正規化
  - カタカナをひらがなにそろえる

### 語の書き方

**語の単純な部分一致ではなく、文脈を含む正規表現で判定します。** 単純な部分一致では、裁定の中心となる報告まで止めてしまうためです。例：

- 「倒れ」だけで判定すると「駒が倒れた」を止めてしまう
- 「叩」だけで判定すると「時計を叩いた」を止めてしまう

**広めに止めるのが安全側ですが、通常の報告を止めた割合は評価で測ります**（設計書 §9。カテゴリごとに5%以下）。表記ゆれ（漢字・ひらがな・カタカナ）は、下の表の正規表現に明示しています。

### 判定に使う語

| 区分 | 判定する正規表現（案） |
| --- | --- |
| フェアプレー・不正疑惑（既存） | 既存の `mentionsFairPlay` をそのまま使う（`lib/domain/llm/keyword-classifier.ts`）。次の語を判定します。<br>・不正（「不正確」「不正な手」等は除く）、カンニング、チート<br>・検査の拒否、金属探知<br>・外部の情報・助言・援助、エンジンの使用<br>・英語の fair play、cheat、engine assistance 等 |
| フェアプレー・不正疑惑（追加案） | `(不正\|カンニング\|ソフト\|エンジン\|外部\|スマホ\|スマートフォン\|機器).{0,8}(疑\|うたが\|怪し\|あやし\|不審)`<br>`(疑\|うたが\|怪し\|あやし\|不審).{0,8}(不正\|カンニング\|ソフト\|エンジン)`<br>`サインを?(送\|出)\|合図を?(送\|出)\|カンペ` |
| 健康・医療 | `体調\|体の具合\|(気分\|体\|お腹\|おなか\|頭)が?.{0,2}(悪\|わる\|痛\|いた)`<br>`病気\|病院\|医務\|救急\|救護\|発作\|持病\|アレルギー\|妊娠\|診断`<br>`(怪我\|けが\|ケガ)\|出血\|嘔吐\|吐き気\|めまい\|発熱\|熱が(ある\|出)`<br>`服薬\|薬を(飲\|の)\|薬の(服用\|副作用)`<br>`障害(者\|が(ある\|あり))\|障がい\|車椅子\|車いす\|補聴器`<br>`(人\|選手\|プレーヤー\|観客\|子ども\|子供\|方)(が\|は)?.{0,4}倒れ` |
| ハラスメント・暴力・差別 | `ハラスメント\|セクハラ\|パワハラ\|暴力\|暴言\|差別\|いじめ\|痴漢\|盗撮\|つきまと\|脅(迫\|さ\|し)`<br>`(人\|選手\|相手\|プレーヤー\|観客\|子ども\|子供\|顔\|頭\|体\|肩)を?.{0,3}(叩\|たた\|殴\|なぐ\|蹴\|け[っら])` |
| 犯罪・警察 | `警察\|110番\|盗難\|盗ま\|窃盗\|被害届` |
| 宗教・信条 | `宗教\|礼拝\|お祈り\|信仰` |
| 家族・未成年の事情 | `家庭の事情\|虐待\|保護者.{0,6}(トラブル\|抗議\|口論)` |

初版の案から次の語を外しました。

- **「具合」単独**：「時計の具合が悪い」を止めてしまうため。「体の具合」だけを判定します。
- **主語の「手」**：「手を叩いて」（拍手）を止めてしまうため。
- **「疑い」単独**：「違法手の疑い」を止めてしまうため。
- **「サイン」単独**：§20 の「サイン漏れ」を止めてしまうため。
- **「通報」単独**：「アービターに通報」を止めてしまうため。
- **「熱」単独**：「熱戦」を止めてしまうため。
- **「障害」単独**：「障害物」を止めてしまうため。

### 止めてはいけない文（回帰テストに入れます）

次の文が送信禁止にならないことを、単体テストと評価の両方で確認します。

- 駒が倒れた
- 時計を叩いた
- 時計を乱暴に押した
- 時計の具合が悪い
- 違法手の疑いがある
- サイン漏れ
- 熱戦の末に時間切れ
- アービターに報告した
- 薬指で駒を動かした
- スマホが2台鳴った
- 白が手を叩いて時計を押した
- 相手の時計を叩いた

### レビューで判断していただきたい点

- 上の語の過不足（特に「家族・未成年の事情」の範囲）。
- 「スマホが鳴った」はフェアプレーではなく player-behavior として送ります。ただし「スマホ」と「疑い」が一緒に現れる場合は送信しません。この線引きでよいか。
