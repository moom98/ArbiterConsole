# FIDE Rules and Regulations

This directory contains official FIDE (Fédération Internationale des Échecs) rules and regulations.

## Contents

This directory will include:

- **FIDE Laws of Chess** - Current version of the official chess rules
- **Competition Regulations** - FIDE tournament and competition regulations
- **Arbiter Guidelines** - Official guidance for arbiters
- **Related Official Documents** - Other relevant FIDE publications

## Version Management

**Critical:** Do not use outdated rules as current rules.

For each document, maintain the following metadata:

- **Document Name** - Full official title
- **Version** - Version number or identifier
- **Published Date** - When the document was published
- **Effective Date** - When the rules become/became effective
- **Source URL** - Official FIDE source link
- **Status** - `active` or `superseded`

### Example

```
Document: FIDE Laws of Chess
Version: 2023 Edition
Published: 2023-01-01
Effective: 2023-01-01
Source: https://www.fide.com/...
Status: active
```

## Important

Always verify that you are using the current, active version of FIDE rules when providing ruling support.

If a newer version supersedes an older one, clearly mark the old version as `superseded` and retain it for historical reference only.
