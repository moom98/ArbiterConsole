# JCF (Japan Chess Federation) Rules and Resources

This directory contains rules, regulations, and arbiter resources from the Japan Chess Federation.

## Contents

This directory will include:

- **NA Seminar Materials** - National Arbiter seminar documentation and training materials
- **Domestic Competition Rules** - Japan-specific chess competition regulations
- **JCF Official Publications** - Official documents published by JCF

## Usage

These materials serve as reference for rulings specific to tournaments held in Japan or under JCF regulations.

When JCF rules differ from or supplement FIDE rules, they should be explicitly documented and referenced in the system.

## Note

Actual PDF files and materials have not been added yet. This directory structure is prepared for future content.
