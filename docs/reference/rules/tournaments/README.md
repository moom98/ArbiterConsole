# Tournament-Specific Rules

This directory contains rules, regulations, and requirements specific to individual tournaments.

## Purpose

Tournament-specific rules (tournament prospectus, special regulations, custom provisions) can override or supplement general FIDE/JCF rules.

These must be explicitly managed and referenced, as they may significantly impact ruling decisions.

## Contents

For each tournament, store:

- **Tournament Prospectus** - Official tournament announcement and regulations
- **Competition Rules** - Specific rules for that tournament
- **Special Provisions** - Any custom rules or variations
- **Organizer Guidelines** - Additional instructions from organizers

## Management Policy

**All tournament-specific rules must be explicitly documented and versioned.**

Tournament rules may:
- Add restrictions not present in FIDE/JCF rules
- Override certain provisions (where permitted)
- Specify time controls, tiebreak systems, and other parameters
- Define behavior for specific scenarios

## Integration

When providing ruling support, the system should:

1. Check if tournament-specific rules apply
2. Identify any conflicts or overrides with general rules
3. Give priority to tournament-specific rules where applicable
4. Clearly indicate when tournament rules are being applied

## Note

Actual tournament documents have not been added yet. This directory structure is prepared for future content.
